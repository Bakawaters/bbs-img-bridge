# 柏宝书生图桥接（bbs-img-bridge）

把**柏宝书维护的当前场景**变成一条 `/sd` 命令，交给酒馆出图。

v2.0 是一次减法：v1.x 里那套"用规则拼提示词"的组装层（bbox 布局、朝向推断、交互动词→构图、时间→光线词表、标点归一化、按句读截断、画风自检）全部删掉。原因是镜头描述已经交给 LLM 写了，那些规则在实际路径上从来没被执行过。

## 它现在只做四件事

1. 从柏宝书快照里取**画面镜头**：`vars.situation`（也认 `画面` / `镜头` / `shot` / `visual`），没有则回退 `sceneFocus.situation`。
2. 拿到镜头 → **原文直通**，一个字不改，只可选地在最前面加一段画风前缀。
3. 拿不到镜头 → 用**场景 desc + 在场人物的外貌/服装/状态**拼一句最小兜底。
4. 拼成 `/sd extend=false <提示词>` 提交，按 `revision + 提示词` 去重。

宽高不传，交给酒馆 Image Generation 面板。

## 命令

| 命令 | 作用 |
|---|---|
| `/bbs-img` | 按当前场景出图 |
| `/bbs-img preview` | 看提示词来自哪里（不消耗 GPU） |
| `/bbs-img preview+` | 打印完整提示词与提交命令 |
| `/bbs-img raw` | 倾倒柏宝书快照（排查用） |
| `/bbs-img rawcmd` | 打印上一次提交的命令 |
| `/bbs-img ghosts` | 看有几个幽灵楼、是否已排除出柏宝书记忆 |
| `/bbs-img on` / `off` | 收到 AI 消息自动出图 |
| `/bbs-img style=水粉厚涂，可见笔触` | 画风前缀，拼在镜头原文最前 |
| `/bbs-img style=auto` | 清空画风前缀 |
| `/bbs-img reset` | 清去重记录 |

## 依赖

- SillyTavern ≥ 1.12.13
- [柏宝书](https://github.com/baibai-git/ST-BaiBai-Book)，且这个聊天有记忆数据（`getSnapshot()` 可用）
- 酒馆 SD 扩展已连上 ComfyUI，工作流是 MOSS 的

## 幽灵楼不参与柏宝书记忆（v2.1）

你用消息菜单里的**幽灵按钮**把某楼移出 AI 上下文后（ST 里那条消息左侧会出现 👻，本质是 `is_system=true`），柏宝书 1.3.5 仍会把它当真实 AI 回复摘进记忆，再以摘要形式注回上下文——等于绕过你的隐藏操作。本扩展不改柏宝书一行代码，只做一件事：扫到这种楼，就给它打上柏宝书公开认可的「番外」标记（`extra.bbs_omit`）+ 来源标记（`extra.bbs_omit_by`），柏宝书据此完全不摘、不注入、不重放。

判定：`is_system=true` 且不是柏宝书自己隐藏的（无 `extra.bbs_hidden`）、不是原生系统楼（无 `extra.type`）、不是带数据开新聊天时的锚点楼（无种子叶子）。

- 楼恢复可见 → 自动撤回标记，记忆照旧恢复。
- 你在楼内面板手动把番外点掉 → 视为你的决定，不再强加。
- 触发时机：加载扩展、切聊天、收到/渲染新楼、聊天区任意点击（含点幽灵按钮）后 300ms。
- `/bbs-img ghosts` 可随时查看当前状态。

### 为什么标记不能只看 `bbs_hidden`（v2.1.1 修的坑）

柏宝书的滑动窗口同步（`syncWindowHiddenState`）会给「窗口外、已被覆盖、还没打 `bbs_hidden`」的楼**补写** `bbs_hidden`——它不区分这楼是自己藏的、还是你藏的。如果桥接用「没有 `bbs_hidden` 才算幽灵楼」来判定，那么这条楼被补写的那一刻标记就会被撤回，柏宝书随即把它当「自家的隐藏旧楼」重新排队摘要 → 楼内面板显示「待摘要」。

所以 v2.1.1 起，**状态以桥接自己的 `bbs_omit_by` 标记为准**，不看 `bbs_hidden`；只有楼真正恢复可见（`is_system=false`）才撤回。

顺带修已经坏掉的聊天：`is_system` + `bbs_hidden` + **从来没有摘过**（无叶子）+ 非用户楼 + 非系统楼，基本只可能是被补写误判的那种（柏宝书只隐藏已经摘过的楼），会自动补上标记，把它们从「待摘要」里拿掉。

## 边界

- 镜头写得好不好，取决于写镜头的那套提示词，不取决于本扩展。它只负责搬运。
- 兜底路径不猜光线、不猜构图、不排位置。没镜头时多人同框的效果就是"各画各的"。
- 支持自然语言，不支持权重语法（`(word:1.5)` 会被当字面量喂给 Qwen 编码器）。
